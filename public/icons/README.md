# Icon Placeholders

The manifest.json references the following icon files:

- icon-16.png
- icon-48.png
- icon-128.png

These should be created with your extension's branding.

For testing purposes, you can:

1. Create simple colored squares as PNG files
2. Use an icon generator tool
3. Design custom icons in your preferred graphics editor

Recommended icon sizes:

- 16x16px - Favicon and browser toolbar
- 48x48px - Extensions management page
- 128x128px - Chrome Web Store and installation

Icons should:

- Be clear and recognizable at small sizes
- Use your extension's brand colors
- Have transparent backgrounds
- Be saved as PNG format with appropriate dimensions
